DE STEP 1 • EXTRACTION

Selenium Scraper & REST APIs

Headless Chrome scrapers extract queue values from web portals (NUHS/TTSH) while Python `requests` modules fetch 5-minute rainfall and dengue cluster GeoJSON endpoints.

Extraction Strategy: Headless Browser -> HTML Element Parsing -> Fallback Synthetic Injection if hospital web server blocks connection.
src/extractors/a_and_e_scraper.py Python / Selenium 
from selenium import webdriver
from selenium.webdriver.chrome.options import Options

def scrape_nuhs_wait_times():
    chrome_options = Options()
    chrome_options.add_argument("--headless")
    driver = webdriver.Chrome(options=chrome_options)
    
    driver.get("https://nuhs.edu.sg/ae-wait-times")
    elements = driver.find_elements("class name", "wait-time-val")
    
    data = []
    for el in elements:
        data.append({"hospital": el.text, "wait_hrs": float(el.get_attribute("data-wait"))})
    driver.quit()
    return data
DE STEP 2 • TRANSFORMATION

Pandas Cleaning & Geocoding

Data cleaning pipelines handle missing value imputation, type coercion (`float`/`datetime`), null audit logging, and regex transformations to resolve address lookup failures.

Regex Geocoding: Cleans raw block strings like "Senja Cl (Blk 647A)" into clean road names for OneMap REST API queries.
src/transform/clean_dengue.py Python / Pandas 
import pandas as pd
import re

def clean_dengue_geojson(raw_df):
    # Strip block references via Regex
    raw_df['clean_locality'] = raw_df['locality'].apply(
        lambda x: re.sub(r'\(Blk.*?\)', '', str(x)).strip()
    )
    
    # Handle nulls & type conversion
    raw_df['case_count'] = raw_df['case_count'].fillna(0).astype(int)
    raw_df = raw_df.drop_duplicates(subset=['clean_locality'])
    return raw_df
DE STEP 3 • DATABASE LOAD

PostgreSQL Schema & Ingestion

Data is loaded into PostgreSQL tables using `SQLAlchemy` engines and `psycopg2` batch execution with transaction rollback protection.

Schema Integrity: Relational foreign keys and postal prefix indexing enable high-performance join queries across wait times and weather state.
src/database.py Python / SQL 
from sqlalchemy import create_engine

def load_to_postgres(df, table_name, engine):
    try:
        df.to_sql(
            name=table_name,
            con=engine,
            if_exists='append',
            index=False,
            method='multi'
        )
        print(f"Successfully loaded {len(df)} rows into {table_name}")
    except Exception as e:
        print(f"Database Load Error: {e}")
